# Habits Reminder Bot

Проект Habits Reminder Bot — это Django-приложение с Celery, которое присылает пользователям Telegram-уведомления с напоминаниями о выполнении их привычек в заданное время.

## Описание

Пользователи создают привычки с указанием времени напоминания. Каждую минуту Celery Beat запускает задачу, которая проверяет, есть ли привычки, время которых совпадает с текущим, и отправляет Telegram-уведомления пользователям с соответствующим telegram_chat_id.

## Настройка

Зарегистрируйте Telegram-бота через @BotFather и получите токен.
Укажите токен в настройках проекта (TELEGRAM_BOT_TOKEN).
Убедитесь, что у пользователей в базе заполнено поле telegram_chat_id.

## Запуск
- Запустите Redis (если он не запущен):
```
redis-server
```
- Запустите Celery с периодическими задачами и воркером:
```
celery -A config worker --beat --scheduler django --loglevel=info
```
- Запустите Django-сервер:
```python manage.py runserver```
- 
## Как работает

Пользователь создаёт привычку с указанием времени (часы и минуты, секунды установите "00").
Celery Beat каждую минуту запускает задачу send_due_reminders.
Задача получает текущее время без секунд, ищет привычки с совпадающим временем.
Для каждой такой привычки отправляется Telegram-сообщение пользователю.

## Установка и Запуск Локально

1. **Клонируйте репозиторий**:
   ```https://github.com/VeronikaSidorova/ProjectHabits```
2. Настройте переменные окружения (из .env.sample)
3. Запустите контейнеры: \
```docker-compose up``` \
Приложение будет доступно на http://localhost:8080 (Nginx). \
PostgreSQL на localhost:5433. \
Redis на localhost:6379. \
4. Проверьте состояние: \
```docker-compose ps``` \
```docker-compose logs celery```  # Для Celery \
Healthchecks настроены для Redis, Celery. Если что-то не работает, проверьте логи.

## Инструкция по настройке сервера и CI/CD:
### Настройка сервера
1. Установите Docker и Docker Compose на сервере. 
2. Настройте SSH-доступ для деплоя через GitHub Actions.

### Настройка CI/CD
1. Создайте новый SSH-ключ и добавьте его в секреты GitHub репозитория.
2. Добавьте конфигурацию GitHub Actions в `.github/workflows/ci.yaml` для автоматического деплоя при пуше в основную ветку.
